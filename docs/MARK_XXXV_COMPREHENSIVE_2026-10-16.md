# Mark XXXV 35.0.3 — capability and state-integrity refinement

This release integrates the focused workflow/file corrections following 35.0.2
and a broader capability review. The dated release report records the exact
source/build/install acceptance and available environment; this guide alone is
not an installation receipt.

The refinement preserves the complete tool, page, plugin and fallback inventory.
It concentrates on preventing wrong actions and lost state: complete workflow
arguments, conservative restart recovery, damaged provider-policy preservation,
guarded file undo, literal memory deletion, research-ledger change detection and
stable selected-task actions. Command-deck feedback and approval labels reflect
the actual operation identity.

Damaged or externally changed saved state now produces an actionable refusal
where the operation cannot be carried out safely. Already admitted workflow
snapshots remain immutable. Interrupted or uncertain actions are not automatically
replayed. A configured provider, dependency or saved artifact is not proof of
live service readiness or factual research quality.

The report includes a complete named capability matrix, deterministic test scope,
UI fixture images, workflow/command-deck proposals and a refreshed remaining-work
prompt. Real account delivery, physical devices, normal installed startup timing,
provider inference quality, hard native cancellation and cross-process transactional
state remain separate acceptance work. No new speed multiplier is claimed by this
correctness refinement.
