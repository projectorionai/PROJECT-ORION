# ── O.R.I.O.N. runtime requirements ────────────────────────────────────────
# The full-feature install — what the release build and CI use:
#     python -m pip install -r requirements.txt
#
# Or choose groups. The desktop core alone starts ORION, talks, routes every
# tool and remembers; each other group adds capabilities that report a clear
# "not installed" message when absent:
#     python -m pip install -r requirements/core.txt -r requirements/speech.txt
#
# Smaller installs save disk and install time. They do not by themselves save
# memory while running: ORION imports optional packages only when a feature
# that needs them is used.

-r requirements/speech.txt
-r requirements/vision.txt
-r requirements/research.txt
